# portfolio# anujpandya.info — Personal Portfolio

> Live at **[anujpandya.info](https://anujpandya.info)**

A single-page personal portfolio built to replace the resume handoff. When someone asks for my resume, I send them here instead.

---

## What's on it

- **Hero** — Quick intro with live stats (10+ years, 3 startups, 400+ sites, 90% latency reduction)
- **Projects** — I AM, Fresh Dabba, VillageConnect, PawsConnect — each linking to their live site
- **Experience** — Samsung, Google, Tailored Brands, HPE
- **Skills** — Grouped by domain: PM, Data, Cloud, Frontend/Mobile, Backend, Tools
- **QR Code** — Floating button that opens a scannable QR modal for in-person sharing

---

## Tech

- Pure HTML/CSS/JS — zero dependencies, zero build step
- Fonts via Google Fonts (Playfair Display, DM Mono, Instrument Sans)
- Photo and QR code embedded as base64 — fully self-contained, one file
- Deployed via Vercel, domain via Porkbun

---

## Updating

Edit `index.html` → commit to `main` → Vercel auto-deploys in ~15 seconds.
